# Getz-Pharma-Customer-Segmentation

A Streamlit dashboard that uses K-Means clustering to group customers by their buying behaviour. Built as a learning project using a synthetic pharmaceutical customer dataset.

## Features
- Dataset preview, city and customer-type filters, and CSV download.
- Elbow chart and adjustable number of clusters.
- Customer counts or percentages, scatter chart, and segment summaries.
- City-wise segment comparison and a learning summary.

## Run Locally
pip install streamlit pandas scikit-learn
streamlit run pharma.py

Keep getz_pharma_customer_segmentation_1000.csv in the same folder. Replace pharma.py with your Python filename if different.

## Tools
Python, Streamlit, pandas, and scikit-learn, and Plotly.
